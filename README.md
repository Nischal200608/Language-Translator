Language Translation Tool

A language translation web application built using Python and Streamlit to translate text between multiple languages.

 Live Demo
 https://language-translator-6qvfg4zydbzjtganlgzw7z.streamlit.app/

Features
- Translate text between multiple languages
- Select and swap languages
- Simple and user-friendly interface

Technologies Used
- Python
- Streamlit
- Requests

Run Locally

pip install -r requirements.txt

python -m streamlit run app.py
